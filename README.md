# 텍스트 이펙트 랩 (Text Effect Lab)

입력한 텍스트를 한 글자씩 분해해서 다양한 이펙트로 터뜨려 보여주는 웹 토이입니다.
빌드 도구나 의존성 없이 **HTML 파일 하나**로 동작합니다.

👉 **https://gilgilolof.github.io/text-effect-lab/**

## 이펙트 10종

| | | |
|---|---|---|
| 1. 네온 — 글로우 펄스 | 2. 글리치 — RGB 분리 | 3. 타자기 — 커서 깜빡임 |
| 4. 무지개 — 그라데이션 웨이브 | 5. 젤리 — 탄성 바운스 | 6. 3D 플립 |
| 7. 화염 | 8. 매트릭스 | 9. 분해 — 글자 흩어짐 |
| 0. 스탬프 | 🎲 랜덤 | |

## 기능

- 이펙트마다 색이 맞춰진 **파티클**이 글자 위치에서 터집니다 (Canvas)
- **글자 크기 / 속도(0.3~2.5배) / 파티클 양** 실시간 조절
  - 속도는 CSS 애니메이션과 파티클 물리에 동시 반영됩니다

## 조작

| 입력 | 동작 |
|---|---|
| `Enter` | 터뜨리기 |
| `Space` | 랜덤 이펙트로 다시 |
| `1` ~ `0` | 이펙트 바로 선택 |
| `Esc` | 입력창 포커스 해제 |

## 공유 링크

🔗 버튼을 누르면 **지금 보고 있는 텍스트와 이펙트를 그대로 재현하는 링크**가 만들어집니다.

- 모바일에서는 네이티브 공유 시트가 열려 카카오톡·메시지로 바로 보낼 수 있습니다
- 데스크톱에서는 링크가 클립보드에 복사됩니다
- 상태는 쿼리스트링에 담깁니다 — `?t=텍스트&fx=이펙트&sz=크기&sp=속도&pt=파티클`
- 주소창은 항상 현재 상태와 동기화되므로, 주소를 그대로 복사해도 됩니다
- 링크로 들어오면 자동 재생되고 "친구가 보낸 이펙트" 배너가 뜹니다

예) https://gilgilolof.github.io/text-effect-lab/?t=%EC%83%9D%EC%9D%BC%20%EC%B6%95%ED%95%98%ED%95%B4&fx=fire

## 모바일

- 반응형 레이아웃 (`dvh` 기반 무대 높이 — 키보드가 올라와도 레이아웃이 깨지지 않음)
- iOS 입력창 자동 확대 방지 (font-size 16px), 더블탭 확대 방지
- 노치/홈 인디케이터 대응 (`env(safe-area-inset-*)`)
- 이펙트 칩은 가로 스크롤

## 공유 미리보기

카카오톡·슬랙·X 등에 링크를 붙여넣으면 썸네일이 뜹니다 (Open Graph / Twitter Card).
썸네일 이미지는 `og.png` (1200×630).
