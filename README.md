# 텍스트 이펙트 랩 (Text Effect Lab)

입력한 텍스트를 한 글자씩 분해해서 다양한 이펙트로 터뜨려 보여주는 웹 토이입니다.
빌드 도구나 의존성 없이 **HTML 파일 하나**로 동작합니다.

👉 **https://gilgilolof.github.io/text-effect-lab/**

## 이펙트 10종

| | | |
|---|---|---|
| 1. 네온 — 글로우 펄스 | 2. 글리치 — RGB 분리 | 3. 타자기 — 커서 깜빡임 |
| 4. 무지개 — 그라데이션 웨이브 | 5. 젤리 — 탄성 바운스 | 6. 3D 플립 |
| 7. 화염 | 8. 매트릭스 | 9. 분해 — 글자 흩어짐 |
| 0. 스탬프 | 🎲 랜덤 | |

## 기능

- 이펙트마다 색이 맞춰진 **파티클**이 글자 위치에서 터집니다 (Canvas)
- **글자 크기 / 속도(0.3~2.5배) / 파티클 양** 실시간 조절
  - 속도는 CSS 애니메이션과 파티클 물리에 동시 반영됩니다

## 조작

| 입력 | 동작 |
|---|---|
| `Enter` | 터뜨리기 |
| `Space` | 랜덤 이펙트로 다시 |
| `1` ~ `0` | 이펙트 바로 선택 |
| `Esc` | 입력창 포커스 해제 |

## 실행

open index.html
